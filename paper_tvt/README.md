# paper_tvt — IEEE TVT journal draft (internal, v0.1)

Merges the two WCNC 2027 papers and the planned journal extensions.
Text is written and revised by the authors; numbers come only from
`numbers_p1.tex` / `numbers_p2.tex` (conference results, to be regenerated)
and later from `numbers_tvt.tex` (scripts/tvt_make_paper.py).

Colour code: black = conference content (rewritten); orange = proposed
new method/analysis, not yet implemented; red = TBD.

Build: `pdflatex main && bibtex main && pdflatex main && pdflatex main`
